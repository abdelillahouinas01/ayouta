# JUI — Interactive Love Page

A polished single-page experience built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Canvas star field
- Interactive 3D-like heart movement
- Animated glassmorphism cards
- Quote carousel
- Revealable final message
- Responsive mobile layout
- Reduced-motion accessibility support

## Files

- `index.html` — page structure and English messages
- `style.css` — visual design, animations and responsive layout
- `script.js` — particles, interactions, quotes and effects

## Run

Open `index.html` in a modern browser.

No Node.js, build tools, or installation are required.

## Customize

Edit the visible text in `index.html`.
Edit the quote list in `script.js`.
Edit colors from the `:root` variables in `style.css`.
